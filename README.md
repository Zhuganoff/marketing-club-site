# Marketing Club — сайт

Публичный лендинг проекта Marketing Club — локальной диспетчерской маркетинговых ИИ-команд.

- `index.html` — лендинг (стиль «инженерный бланк», мобильная версия, без внешних зависимостей кроме Google Fonts).
- `cabinet.html` — вход в личный кабинет: страница проверяет, запущена ли локальная панель на `127.0.0.1:4310`, и переводит в неё; если панель не запущена — объясняет, как её запустить.

Сам кабинет работает только локально (данные не покидают компьютер владельца); основной код — в приватном репозитории `marketing-club`.
